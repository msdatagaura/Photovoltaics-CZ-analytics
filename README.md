# Photovoltaics-CZ-analytics
Dashboard o vývoji fotovoaltiky v ČR v Power BI. Dáta boli získané z verejných zdrojov, ktoré poskytovali verejné informácie o inštaláciách FVE. This dashboard regarding photovoltaics in the Czech Republic was created using Power BI. The data comes from public sources that collect information on installations in the Czech Republic.
